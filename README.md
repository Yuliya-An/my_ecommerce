# My E-commerce Core

Проект представляет собой базовое ядро для интернет-магазина, реализованное с использованием ООП. Основная цель — создать структуру для управления товарами и категориями.

## Описание проекта
В ходе работы были созданы основные сущности магазина: классы Product и Category. Реализована логика инициализации объектов и автоматический подсчет общего количества категорий и товаров в системе.

## Реализованный функционал
- Класс Product: хранит информацию о названии, описании, цене и количестве товара.
- Класс Category: объединяет товары в группы, ведет учет общего числа категорий и продуктов.
- Загрузка данных: добавлена функция для чтения файла products.json и создания на его основе объектов классов.
- Тестирование: написаны тесты с помощью pytest для проверки инициализации и работы счетчиков.
- Проверка кода: проект проверен с помощью flake8 на соответствие PEP 8 и mypy на корректность типов.

## Стек технологий
- Python 3.10+
- Poetry (управление зависимостями)
- pytest, flake8, mypy

## Инструкция по запуску

1. Установка зависимостей:
   poetry install

2. Запуск программы:
   poetry run python src/main.py

3. Запуск тестов:
   poetry run python -m pytest

4. Проверка стиля и типов:
   poetry run flake8 --max-line-length=120 src/main.py
   poetry run mypy src/main.py
